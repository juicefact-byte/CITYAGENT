# CITYAGENT — MVP Scope Freeze (v1)

> Anything not listed here is Phase 2/3. Say no by default.

## Pilot city: Abuja (Wuse test area)
- **Why:** PRD examples already use Abuja/Wuse; strong rental demand, large mover/student/worker population, active market.
- **Target:** 100–300 real verified listings before expanding (City1 → City2 → national).

## IN — User side
Register/login (email OTP), browse, search + filters (location/type/price/bedrooms/verification/features), location + OSM map + near-me, property details + 5–10 photos + full price breakdown + badges, call/chat (in-app), favorites, report listing, viewing request, notifications (message/viewing/verification/expiry).

## IN — Owner side
Register, identity verification (L1-L2), property submit, property verification (L3-L4), photos/price/features, manage listings (edit/reprice/unavailable/rented), chat, accept/reject/counter viewings.

## IN — Admin side
User management, property approval queue, verification review, fraud reports, listing/complaint management, basic analytics (users, verified props, searches, views, chats, viewings, reports).

## OUT (Phase 2)
Online rental payments, hotel booking checkout, property comparison, AI search/assistant, featured listings, subscriptions, virtual tours, advanced analytics.

## OUT (Phase 3)
CITYAGENT Pay / Move / Services / Inspect ecosystem.
