# CITYAGENT — UX Flows (MVP journeys)

## F1 Renter journey (§54)
Home (Rent/Hotel + Where + Budget) → Search → filter Verified Owner → Property (photos/price/costs/verification) → Chat → Request inspection → Visit → Review.

## F2 Hotel journey (§55)
Hotel/Short-stay → destination + dates + budget → list (photo/amenities/reviews/verification) → contact → confirm (booking checkout = Phase 2).

## Screens (Penpot/Figma Free)
1. Home 2. Search+Filters 3. Map+Near-me 4. Details 5. Chat 6. Owner Submit wizard 7. Owner Dashboard 8. Admin Review queue 9. My Dashboard 10. Report sheet.

## Rules
Badge before contact · approx map default · safety banner on details + viewing · every submit lands in review queue (never auto-publish).
